AUTO TYPER FOR VM (NOTEPAD)
================================

KAAM KAISE KARTA HAI:
1. Agar naya code badalna ho to isi folder me 'code.txt' open karein, apna code paste karein aur save (Ctrl+S) kar dein.
2. VM me Notepad (ya Browser Console) open karein.
3. 'Run_Typing_PS.bat' par double-click karein.
4. 7 seconds ka countdown chalega, VM ke andar Notepad par click kar dein.
5. Code automatic type ho jayega!
